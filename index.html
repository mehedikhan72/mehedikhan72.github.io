Projects

Live Election Monitoring System

Netra News · 2026
Blog Post /

Systems, backend and infrastructure lead for Netra News' live election monitoring platform covering Bangladesh's 2026 national election - 300 constituencies, ~43,000 polling stations. Built as a static Next.js site using Incremental Static Regeneration, triggered by authenticated webhooks on each result entry, backed by a FastAPI monolith and a PostgreSQL primary/replica pair with two-layer connection pooling. Deployed on a DigitalOcean Kubernetes cluster behind Cloudflare (WAF, DDoS protection, Tunnels in place of a load balancer). Served roughly 8 million requests at 100% uptime for about $335 in infrastructure cost for the month.
